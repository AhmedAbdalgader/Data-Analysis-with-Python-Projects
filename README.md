# Data-Analysis-with-Python-Projects
For the projects to compelete the course of Data Analysis with Python from the FreeCodeCamp
The course provides the fundamentals of data analysis with Python. Focuses on Numpy, Pandas, Matplotlib, and Seaborn to process and visualize data
The are five projects as part of the course to gain the certificate.
I will dedicate a branch for each of them.
They are the following:
1. Mean-Variance-Standard Deviation Calculator
2. Demographic Data Analyzer
3. Medical Data Visualizer
4. Page View Time Series Visualizer
5. Sea Level Predictor
